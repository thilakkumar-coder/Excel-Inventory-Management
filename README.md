# Excel-Inventory-Management
# 📊 Excel Inventory Management Dashboard

## 📌 Overview

This project is an **Excel-based Inventory Management Dashboard** designed to monitor stock levels, inventory movement, product performance, and overall inventory status. The dashboard provides a clear and interactive view of key inventory metrics to support better decision-making.

## 📂 Dataset

The dataset contains inventory-related information such as:

* Product Name
* Product Category
* Stock Quantity
* Sales Quantity
* Purchase Quantity
* Unit Price
* Total Sales
* Supplier Details
* Inventory Status

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Conditional Formatting
* Data Cleaning
* Slicers
* Dashboard Design

## 🔄 Project Steps

1. Imported the inventory dataset into Excel.
2. Cleaned and formatted the data.
3. Applied Excel formulas for calculations and analysis.
4. Created Pivot Tables to summarize inventory data.
5. Built charts and KPIs to track inventory performance.
6. Added slicers for interactive filtering.
7. Designed an interactive Inventory Management Dashboard.

## 📈 Dashboard

The dashboard provides insights into:

* Total Products
* Total Stock
* Total Sales
* Low Stock Products
* Inventory by Category
* Product-wise Stock Levels
* Sales and Inventory Trends
* Inventory Status

## 🔑 Key KPIs

* **Total Products**
* **Total Stock Quantity**
* **Total Sales**
* **Low Stock Count**
* **Out-of-Stock Products**
* **Inventory Value**

## 📊 Key Insights

The dashboard helps identify:

* Products with low or insufficient stock.
* Categories with higher inventory levels.
* Best-performing products.
* Stock availability and inventory status.
* Overall inventory trends.

## 🎯 Objective

The main objective of this project is to create an **interactive Excel dashboard** that makes inventory data easier to monitor, analyze, and understand.

## 🚀 How to Use

1. Download the Excel file from this repository.
2. Open the `.xlsx` file using Microsoft Excel.
3. Use the slicers and filters to explore the dashboard.
4. Review the KPIs, charts, and inventory insights.
